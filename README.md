# الوتين الذكي — HTML وCSS وJavaScript

## فتح الموقع

افتح index.html مباشرة بالنقر المزدوج، أو افتح start.cmd. لا يحتاج الموقع إلى Node أو npm أو خادم أو قاعدة بيانات.

## الملفات المستخدمة

- index.html: الصفحة الرئيسية، موجودة في جذر المشروع.
- assets/css/styles.css: التصميم.
- assets/js/app.js: البحث وعرض الخدمات والتواصل.
- assets/images/: الشعار وصورة بيانات السجل التجاري.
- data/site-data.js: جميع الخدمات والأسعار وبيانات المكتب في ملف واحد.

## الرفع على Cloudflare أو أي استضافة ملفات ثابتة

1. شغّل prepare-upload.cmd.
2. افتح خيار Upload your static files.
3. ارفع upload/alwateen-website.zip.

الملف المضغوط يحتوي index.html في الجذر ومعه assets وdata فقط. لا ترفع مجلد المشروع كاملًا؛ archive وbackups يحتويان نسخ العمل القديمة، وtools أداة محلية وليست للإرفاق بالموقع.

يمكن بدل ZIP رفع index.html ومجلدي assets وdata معًا، مع الحفاظ على المسارات.

## تعديل الأسعار والخدمات

افتح tools/editor.html مباشرة. يمكنك تعديل سعر، تعطيل خدمة وإعادة تفعيلها، حذف خدمة، إضافة خدمة جديدة، وتعديل بيانات المكتب.

للحفظ المباشر داخل المشروع، اضغط «اختيار مجلد المشروع» واختر المجلد الذي يحتوي index.html. بعد التعديلات اضغط «حفظ ملف البيانات». يدعم ذلك متصفحات Chrome وEdge التي توفر اختيار المجلد.

إذا لم يدعم المتصفح الحفظ المباشر، اضغط «حفظ ملف البيانات» لتنزيل site-data.js، ثم استبدل به data/site-data.js داخل المشروع.

بعد الحفظ حدّث معاينة الموقع، وشغّل prepare-upload.cmd وارفع ZIP المحدّث. الموقع المنشور ثابت؛ لا توجد إدارة أونلاين ولا مزامنة تلقائية. لا تُستخدم localStorage أو طلبات API لتخزين الأسعار.

## النسخ السابقة

التنفيذ السابق بـNode وCloudflare Workers محفوظ داخل archive/previous-cloudflare للرجوع إليه فقط. لا يُستخدم عند فتح أو رفع الموقع الجديد.

## التحقق

تم فحص فتح index.html مباشرة دون خادم، وظهور 294 خدمة، والبحث والتواصل والشعار والرقم الموحد. تم فحص العرض على الكمبيوتر والجوال، وتعديل الأسعار والتعطيل والإضافة والحذف وتنزيل ملف البيانات من الأداة المحلية.
